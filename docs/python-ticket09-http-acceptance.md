## 兼容差异

审核摘要、运行列表/详情为额外只读接口，不计入原 98；当前 key 及归属校验。feedbackRevision 必须绑定用户所见卡片，拒绝重规划递增版本，事件含完整 plan/threadId/planRevision。stop 必填 agentId/conversationId，可选 threadId，成功 204。标题 SSE 增加鉴权；执行流不自动重连。删除遇非终态整体 409，晚到数据 404。展示消息 messageKey 幂等，内容冲突 409。历史 PYTHON 只读展示。Python 文件使用内容寻址 /api/upload/files，迁移转换 Java uploads 前缀。数据源仅 MySQL/PostgreSQL，未知驱动参数拒绝。Embedding 在线热切换守卫保留，停服 CLI 两阶段重建。HTTP 200 success=false 是业务失败，参数错误 400；未列管理入口仍是本机管理。

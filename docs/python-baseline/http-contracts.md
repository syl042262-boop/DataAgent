# 98 个接口契约矩阵

矩阵记录上游接口基线及对应的 Python 实现。逐接口运行验证见 [Ticket 09 HTTP 验收](../python-ticket09-http-acceptance.md)。

参数栏保留完整绑定注解：PathVariable=路径，RequestParam=查询，RequestBody=JSON，RequestPart=multipart；required 未写默认为 true，required=false 的引用类型默认为 null、boolean 为 false。defaultValue 如实保留。DTO 字段/校验/初值见 [schema catalog](schemas.md)。返回类型中的泛型是准确响应包裹。

Python 绑定/验证错误约定 HTTP 400；Java GlobalExceptionHandler 的 generic Exception 分支为 500，属于显式差异。管理接口未增加鉴权（开放本机管理）；search 使用当前 Agent key，Python 的 stop/标题/运行扩展增加同样鉴权，详见 [公共协议](../python-runtime-contract.md)。响应为 ApiResponse.error 时，即使状态码为 HTTP 200 也表示业务失败。日期/字段别名以 schema catalog 注解为准，null 保留，分页字段不得更名。
